# COYU Host Ops SMS Information

COYU uses Host Ops to send operational cleaning-schedule reminders to cleaners who have
verbally opted in.

- [SMS Privacy Policy](privacy-policy.md)
- [SMS Terms and Conditions](sms-terms.md)

For assistance, reply **HELP** to a Host Ops message or email
[colca7@gmail.com](mailto:colca7@gmail.com). Reply **STOP** to opt out. Message
frequency varies based on reservations. Message and data rates may apply.
